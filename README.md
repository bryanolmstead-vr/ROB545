# ROB545
Final Project for ROB545 - Visual Servoing

## Proposal

Our [proposal](docs/ROB545-Final-Project-Proposal-2026.10.12.pdf) was submitted on 10/12/2026. We are implementing visual servoing of a simulated object with a simulated UFactory-850 robot using ROS2 and Gazebo.

## Installation

This is our installation procedure so far. 

### ROS2

Install [ROS2 Jazzy](docs/ros2_installation.md).

### UFactory-850 Driver 

Install [UFactory-850 ROS2 Driver](docs/ufactory850_installation.md).

### Gazebo

Test UFactory-850 robot in Gazebo after installing UFactory-850 driver. Use these [instructions](docs/gazebo_usage.md).
